# Orderly AI Assistant

Voice-Driven Agentic AI System for Order Tracking and Customer Support in Retail. Problem Statement: Retail businesses handle a high volume of customer calls related to order tracking, delivery updates, cancellations, and returns. Manual handling of these queries is time-consuming, costly, and often leads to delays and inconsistent service. Traditional IVR systems lack intelligence and cannot provide personalized, end-to-end assistance. There is a need for an autonomous voice-based system that understands customer intent and executes tasks independently. This project proposes a Voice-Driven Agentic AI System to automate order management and customer support, improving efficiency and customer satisfaction
build solution for this with more advanced ui and and high frontend
